# KarasuLover

小烏鴉會員影片批次下載工具

作者：阿冰 (Abing.)

## 功能特色

- 批次下載 YouTube 影片（支援會員限定內容）
- 內建 728 支影片清單（含標題）
- 搜尋過濾影片
- 自動標註已下載的影片
- Cookie 管理（會員影片需要）
- 深色主題介面

## 使用方式

### 1. 取得 Cookie

會員影片需要 Cookie 才能下載：

1. 安裝瀏覽器擴充功能 [Get cookies.txt LOCALLY](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)
2. 開啟 YouTube 並登入帳號
3. 打開會員影片頁面
4. 點擊擴充功能圖示，匯出 `cookies.txt`

### 2. 載入 Cookie

1. 開啟 KarasuLover
2. 點擊「載入 Cookie」
3. 選擇剛才匯出的 `cookies.txt`

### 3. 下載影片

1. 勾選要下載的影片（可用搜尋框過濾）
2. 選擇儲存位置
3. 點擊「開始下載勾選項目」

## 介面說明

| 按鈕 | 功能 |
|------|------|
| 全選 / 全不選 | 勾選或取消所有影片 |
| 重新載入清單 | 重新讀取影片清單 |
| 檢查已下載 | 標註已存在於下載資料夾的影片 |
| 搜尋 | 輸入關鍵字過濾影片標題 |
| 使用說明 | 顯示詳細使用指南 |

## 注意事項

- 沒有 Cookie 只能下載公開影片
- 會員影片必須有有效的 Cookie
- Cookie 過期時需重新匯出
- 下載的檔案會以「日期 標題.mp4」命名

## 系統需求

- Windows 10/11 (64位元)
- 已打包的 EXE 無需額外安裝
